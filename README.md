<article class="card" id="security">
<span class="tag">ネット安全</span>
<h3>ネット詐欺を見分けるための7つのチェックポイント</h3>
<p>「アカウントが停止されます」「至急お支払いください」といったメッセージが届いたときは、慌てずに確認しましょう。</p>
<ul>
<li>送信元のメールアドレスや電話番号を確認する。</li>
<li>メッセージ内のリンクをすぐに開かない。</li>
<li>パスワードや認証コードを他人に教えない。</li>
<li>「本日限り」など、極端に急がせる表現を警戒する。</li>
<li>公式アプリや自分で開いた公式サイトから状況を確認する。</li>
<li>不自然な日本語や、見慣れないドメインに注意する。</li>
<li>不安な場合は、家族や公的な相談窓口に確認する。</li>
</ul>
<p><strong>大切なこと：</strong>ロゴや文章が本物らしく見えても、正規の連絡とは限りません。リンク先ではなく、公式アプリなど別の経路から確認する習慣をつけましょう。</p>
</article>

<article class="card" id="ai">
<span class="tag">AI活用</span>
<h3>AIに頼むときに便利な指示の出し方</h3>
<p>AIから役立つ回答を得るには、目的・条件・回答形式を具体的に伝えるのがコツです。</p>
<ul>
<li><strong>目的：</strong>何を達成したいか。</li>
<li><strong>条件：</strong>予算、時間、使える道具など。</li>
<li><strong>形式：</strong>箇条書き、表、手順など。</li>
<li><strong>確認：</strong>不明点や事実確認が必要な部分を示してもらう。</li>
</ul>
<p><strong>指示の例：</strong>「スマホ初心者向けに、写真の整理方法を3つ、手順と注意点を箇条書きで説明してください。無料で使える方法を優先してください。」</p>
<p>なお、AIの回答には誤りが含まれる場合があります。お金、健康、法律、安全に関わる内容は、信頼できる情報源でも確認しましょう。</p>
</article>

<article class="card">
<span class="tag">スマホ活用</span>
<h3>スマホで作業時間を減らす5つの工夫</h3>
<ol>
<li>よく使う文章を辞書登録しておく。</li>
<li>通知を見直し、必要なものだけ残す。</li>
<li>パスワード管理ツールを利用し、使い回しを避ける。</li>
<li>写真やファイルを定期的に整理する。</li>
<li>重要なデータはバックアップを取る。</li>
</ol>
<p>一度にすべて変える必要はありません。毎日繰り返す作業をひとつ選び、少しずつ改善してみましょう。</p>
</article>

<article class="card">
<span class="tag">プライバシー</span>
<h3>アプリに許可する権限を見直そう</h3>
<p>アプリが位置情報、連絡先、写真、マイクなどへのアクセスを求めることがあります。すべてを許可するのではなく、その機能に本当に必要かを考えましょう。</p>
<ul>
<li>使っていないアプリの権限を確認する。</li>
<li>位置情報は必要なときだけ許可できるか確認する。</li>
<li>使わないアプリは削除を検討する。</li>
<li>OSやアプリを最新の状態に保つ。</li>
</ul>
<p>設定項目や名称は、端末やOSのバージョンによって異なります。</p>
</article>
